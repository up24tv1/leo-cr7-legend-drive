# LEO CR7: Legend Drive (v2)

An original arcade supercar racing game for the web, built with three.js as an installable PWA. Play in Safari on iPhone, iPad and Mac, then use Share → Add to Home Screen for full-screen offline play.

Live: https://up24tv1.github.io/leo-cr7-legend-drive/

Binary assets (HDRIs, GLB models, WebP textures and art) are stored as base64 text (`*.b64`) and decoded in the browser.

See CREDITS.md for the asset sources and licences (CC0 / CC-BY 4.0).
