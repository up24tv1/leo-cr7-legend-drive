# LEO CR7: Legend Drive
Original arcade supercar racing web game (Three.js, PWA). Play in Safari on iPhone/iPad/Mac; Share → Add to Home Screen for full-screen offline play.
Controls: touch ◀ ▶ / tilt, BRAKE, NITRO · Keys: ←/→ A/D, ↓/S brake, Space nitro, P pause.
All cars, characters and names are original/fictional.
